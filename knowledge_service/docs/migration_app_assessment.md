# Jira Cloud App Assessment

## Purpose
Before migrating from Jira Data Center to Jira Cloud, Marketplace apps and customizations should be assessed for Cloud availability, migration path, feature parity, and data migration support.

## What To Assess
- Whether a Cloud version of the app exists.
- Whether the vendor provides an automated migration path.
- Whether app data can be migrated.
- Whether important Data Center features exist in Cloud.
- Whether custom scripts or workflow extensions must be rewritten.

## Compatibility Assessment
- An available Cloud app does not guarantee feature parity.
- Automated app migration does not guarantee that custom scripts are valid in Cloud.
- App data migration and script compatibility should be evaluated separately.

## Recommended Migration
- Run a Marketplace app assessment before migration.
- Identify apps with no Cloud equivalent.
- Identify apps with partial Cloud feature parity.
- Review vendor migration documentation.
- Rehearse migration in a sandbox and validate workflows, permissions, custom fields, and automations.
